Getting started with Hector Analytics is quick and easy. Follow these simple steps to start tracking your website visitors while maintaining complete privacy compliance.

## Overview

The installation process consists of three main steps:

1. **[Add Your Website](/docs/installation/add-website)** - Create a new website project in your dashboard
2. **[Install Tracking Script](/docs/installation/tracking-script)** - Add our lightweight script to your website
3. **[Verify Installation](/docs/installation/verify)** - Confirm everything is working correctly

## What You'll Need

- Access to your website's HTML code
- A few minutes to complete the setup
- No technical expertise required

## Quick Start

If you're in a hurry, here's the minimal setup:

1. **Add Website**: Go to your dashboard and click "Add Site"
2. **Copy Script**: Copy the tracking script provided
3. **Paste Script**: Add it to your website's `<head>` section
4. **Verify**: Check that data is coming through

That's it! Your privacy-first analytics are now active.
