# Add Your Website

The first step to using Hector Analytics is to add your website to your dashboard. This process takes just a minute and creates your unique tracking configuration.

## Step-by-Step Guide

### 1. Access Your Dashboard

- Log in to your Hector Analytics account
- Navigate to your main dashboard
- Click the **"Add Site"** button

### 2. Enter Website Details

Fill in the following information:

**Website Domain** (required)
- Enter your website's domain (e.g., `example.com`)
- Don't include `http://` or `https://`
- Subdomains are supported (e.g., `blog.example.com`)

**Website Name** (optional)
- Give your website a friendly name
- This helps you identify it if you have multiple sites
- You can change this later in settings

### 3. Configure Privacy Settings

Choose your privacy level:

**🛡️ Maximum Privacy (Recommended)**
- No cookies used
- IP addresses anonymized
- GDPR compliant by default
- No consent banner required

**📊 Enhanced Tracking**
- Optional: Use session cookies for better attribution
- Requires user consent in some regions
- More detailed user journey tracking

### 4. Generate Tracking Code

Once you click **"Create Website"**, you'll receive:

- Your unique website ID
- Custom tracking script
- Installation instructions
- Verification checklist

## What Happens Next?

After adding your website:

1. **Tracking Script Generated** - You'll get a personalized script
2. **Dashboard Created** - Your analytics dashboard is prepared
3. **Data Collection Ready** - We're ready to receive data
4. **Real-time Monitoring** - Start seeing visitors immediately

## Website Settings

You can modify these settings anytime:

- **Domain**: Change your tracked domain
- **Name**: Update the display name
- **Privacy Settings**: Adjust tracking preferences
- **Data Retention**: Set how long to keep data
- **Team Access**: Add collaborators

## Multiple Websites

Need to track multiple sites? No problem:

- Each website gets its own dashboard
- Data is completely separated
- Unlimited websites on all plans
- Easy switching between projects

## Common Questions

**Q: Can I track subdomains?**
A: Yes! Add each subdomain as a separate website or use wildcard tracking.

**Q: What about staging/development sites?**
A: We recommend separate projects for production and development environments.

**Q: Can I change the domain later?**
A: Yes, you can update the domain in website settings.
