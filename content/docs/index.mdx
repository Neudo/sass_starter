Hector Analytics is a simple, yet powerful solution for privacy-first web analytics. Our goal is to provide you with the most important metrics in a simple and intuitive way. The integration is super easy and only takes a few minutes.

By default, Hector Analytics works without cookies and is GDPR compliant, fully respecting the privacy of your users. On top of that, you have the ability to track custom events and funnels for more robust analytics, all while maintaining complete user privacy.

Here in our documentation you'll find everything you need to install Hector Analytics and start analyzing your data.

## Why Choose Hector Analytics?

Hector Analytics is a modern alternative to traditional analytics platforms, built with privacy at its core:

- **🍪 Cookie-free tracking** - No cookies required, ensuring native GDPR compliance
- **⚡ Lightweight script** - Ultra-fast tracking script under 2KB
- **📊 Real-time analytics** - See your visitor data instantly
- **🤖 Bot detection** - Automatic filtering of bot traffic
- **🛡️ Privacy-focused** - No personal data collection, IP anonymization
- **🎯 Custom events** - Track specific user actions and conversion funnels

## Key Features

### 📈 Real-time Analytics Dashboard

Track your website performance with comprehensive metrics:

- Visitor metrics (page views, unique visitors, session duration)
- Traffic sources (direct, referrals, search engines, social media)
- Geographic data (country and city-level visitor location)
- Device analytics (browser, OS, and device type breakdown)
- Page performance (top pages, entry/exit pages)

### 🔍 Advanced Analysis

- Time range selection (today, yesterday, last 7/30/90 days, custom ranges)
- Multi-dimensional filters (by source, page, country, device, and more)
- Real-time updates (dashboard updates automatically)
- Data export (CSV, JSON formats)

### 🎯 Custom Events & Funnels

- Track specific user actions on your site
- Monitor conversion rates through defined user journeys
- Set and monitor specific business objectives
- Flexible event setup with custom properties
