# Hector Analytics Documentation

Welcome to Hector Analytics - a privacy-first web analytics platform that respects user privacy while delivering powerful insights.

## Why Hector Analytics?

Hector Analytics is a modern alternative to traditional analytics platforms, built with privacy at its core:

- **Cookie-free tracking** : No cookies required, ensuring native GDPR compliance
- **Lightweight script** : Ultra-fast tracking script under 2KB
- **Real-time analytics** : See your visitor data instantly
- **Bot detection** : Automatic filtering of bot traffic
- **Privacy-focused** : No personal data collection, IP anonymization

## Core Features

### Real-time Analytics Dashboard
Track your website performance with comprehensive metrics:
- **Visitor metrics**: Page views, unique visitors, session duration
- **Traffic sources**: Direct, referrals, search engines, social media
- **Geographic data**: Country and city-level visitor location (via MaxMind GeoIP2)
- **Device analytics**: Browser, OS, and device type breakdown
- **Page performance**: Top pages, entry/exit pages, page load times

### Advanced Filtering & Analysis
- **Time range selection**: Today, yesterday, last 7/30/90 days, custom ranges
- **Multi-dimensional filters**: Filter by source, page, country, device, and more
- **Real-time updates**: Dashboard updates automatically with new data
- **Data export**: Export your analytics data (CSV, JSON formats)

### Custom Events & Funnels
- **Custom event tracking**: Track specific user actions on your site
- **Funnel analysis**: Monitor conversion rates through defined user journeys
- **Goal tracking**: Set and monitor specific business objectives
- **Event configuration**: Flexible event setup with custom properties

### Privacy & Compliance
- **GDPR compliant**: No personal data storage, no consent required
- **IP anonymization**: Automatic IP address anonymization
- **Data ownership**: Your data stays in your Supabase database
- **No cross-site tracking**: Each site's data is completely isolated

## Technical Stack

Built with modern technologies:
- **Frontend**: Next.js 15 with App Router, TypeScript
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **UI Components**: shadcn/ui with Radix UI
- **Styling**: Tailwind CSS v4
- **Charts**: Recharts for data visualization
- **Maps**: react-simple-maps with TopoJSON
